# Controls

Open **Settings → Controls** to configure buttons and touch input. The available
options depend on the device. These subpages apply to non-INX themes. INX keeps
the existing flat Controls page: **Side Button Layout (reader)**, **Long-press
Chapter Skip**, **Long-press Menu**, and **Short Power Button Click** retain their
labels and bindings. All themes keep the same six main settings groups.

- **Home button gestures** opens the existing gesture assignments.
- **Power button** contains **Short click** and, on X4 Pro, **Double click**.
- **Front buttons** contains remapping, orientation, Back behavior, and the two
  long-press settings at the bottom.
- **Side buttons** contains the reader layout, orientation, and page-turn long press.
- **Taps and gestures** contains **Touch controls while reading** and the page/menu gestures.

**Page turn long press** is shared by Front buttons and Side buttons. Changing it
in either group changes the same setting.

On X4 Pro, **Double click** offers the same actions as **Short click**, plus
**Frontlight** to toggle the light. With a double-click action enabled, a single
click waits up to half a second before its action runs. A double click runs only
its assigned action. Set Double click to **Ignore** to remove this wait.
Reader actions such as page turn and footnotes apply while reading. Sleep,
screen refresh, Confirm, and the frontlight retain their usual behavior.

On X4 Pro, set **Home button gestures → Tap → Browse Files** to return from
a reading page to the folder containing the current book. You can also assign
Browse Files to Double Tap or Long Press. These assignments apply while reading;
the default Tap action remains Home. Set Double Tap to Ignore if you want a
single tap to act without waiting for a possible second tap.

Side-button layout applies while reading and supports Previous/Next, Next/Previous,
Next/Next, Previous/Previous, and Disabled. **Orient Side Buttons** reverses the
selected layout in either landscape mode when enabled; normal portrait keeps it,
and inverted portrait reverses it regardless of this switch. Equal-action and
disabled layouts are unchanged. The switch defaults off on old settings too.

Existing enabled frontlight double-click settings migrate to the Frontlight
action. Other saved power-action values and Home assignments keep their meaning.
Screenshot combinations, wake gestures and inherited held inputs retain their
release barriers: one gesture performs one action.
