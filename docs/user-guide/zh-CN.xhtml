1. 从这本书开始

欢迎使用 CrossMux！这本精简手册帮助你完成第一次阅读。它是一本文档图书，可以像其他 EPUB 一样翻页、调整字体、添加书签和删除。

在主页的最近阅读中选择一本书并确认，即可继续阅读。文件浏览器用于查找 SD 卡上的图书；最近阅读只显示曾打开的图书，以及首次使用时加入的这本手册。

这本手册只自动投放一次。移除最近阅读记录不会删除图书；删除图书后也不会自动补回。固件更新不会覆盖你已经拥有的手册。

2. 按键与触控

以屏幕底部的操作提示为准。“确认”用于打开选中项，“返回”用于离开当前菜单；方向键用于移动选择，“上一页”和“下一页”用于翻页。

X3、X4 及其他设备的实体按键位置、数量和可用功能不同。按键映射和屏幕方向也会影响操作，请在设置中的控制选项查看或调整映射，不要把某一机型的按键位置套用到其他机型。

仅支持触控的设备可以点按屏幕按钮与列表项目。电子墨水屏刷新较慢，操作后请等待画面更新；偶尔闪黑属于正常刷新。

3. 导入自己的图书

最直接的方法是关机后取出 SD 卡，用读卡器把 EPUB、TXT 或其他受支持的图书复制到卡中，再安全弹出并装回设备。可以用文件夹整理书籍。

也可以从主页进入文件传输，选择无线传书方式，按设备屏幕提示连接网络，并在同一网络内的电脑或手机浏览器打开屏幕显示的地址上传图书。完成后退出传输页面。

部分设备支持 USB 磁盘模式；仅在设备提供该入口时使用。传输完成后先在电脑安全弹出磁盘，再按设备提示退出。不要在写入时拔卡或断电。

导入后回到文件浏览器找到图书，打开一次后就会进入最近阅读。

4. 调整阅读体验

阅读时按确认打开阅读菜单；触控设备可使用屏幕上的阅读菜单入口。你可以查找章节、跳转进度、添加书签，以及调整可用的字体、字号、行距和页边距。

遇到中文缺字，先检查所选字体是否支持中文。需要额外字体时，按字体设置中的提示准备或下载字体。调整字号等排版设置后，设备可能需要重新分页，请稍等。

阅读进度会由阅读器正常保存。这本手册不会因为自动出现在主页，就被算作你已经读过。

5. 返回主页与日常使用

在阅读菜单中选择返回主页，或使用当前设备提供的主页操作。先退出弹窗再离开阅读；具体按键以页面提示为准。

主页可以进入文件浏览器、最近阅读、传输、设置和应用。不同主题的布局可能不同；有些主题使用标签页切换。

在设置中可以更改界面语言、主题和控制方式。前光、触控、自动旋转等功能取决于硬件，某些设备没有相应入口。

6. 常见问题

导入后主页没有新书？先从文件浏览器打开它。最近阅读不是 SD 卡所有图书的列表。

封面或第一页加载较慢？首次打开需要解析图书并建立缓存。请等待；图片多或内容复杂的图书可能更慢。

图书打不开？检查文件是否完整、格式是否受支持，尝试一本已知可用的 EPUB。带 DRM 保护的文件需要通过合法支持该保护的阅读方式使用。

提示 SD 卡错误？关机后检查卡是否正确插入，并在电脑备份重要文件、检查卡的可读写性。不要在尚未备份时格式化。
