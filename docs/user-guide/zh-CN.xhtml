1. 开始使用

《CrossMux 快速用户手册》介绍首次阅读所需的常用操作。CrossMux 是面向 ESP32 墨水屏设备的轻量阅读固件，主要用于阅读 EPUB、TXT 等电子书。

首次使用建议按以下顺序操作：

1. 插入 SD 卡并开机。

2. 选择界面语言。

3. 将电子书复制到 SD 卡。

4. 从“书库”或“浏览文件”中打开图书。

5. 在设置中调整字体、字号和休眠时间。

请勿随意删除 SD 卡中的 /.crosspoint/ 目录；阅读进度、缓存和部分设置保存在这里。

官方网站：https://crossmux.com/

2. 基本按键

不同设备的按键位置和数量可能不同，请以屏幕提示及当前按键映射为准：

  • 确认：打开选中项目或进入菜单。
  • 返回：返回上一层或关闭当前菜单。
  • 上一项／上一页：向前移动或翻页。
  • 下一项／下一页：向后移动或翻页。
  • 电源键：按设备提供的方式开关机、休眠或执行快捷操作。
  • Reset：仅在设备配有复位键且无响应时使用。

部分设备可在“设置 > 控制”中重新映射按键；支持触控的设备也可点按屏幕上的控件。

3. 阅读图书

CrossMux 可浏览 EPUB、TXT、XTC／XTCH，以及 BMP、JPEG 等图片文件。可用格式和操作因设备而异。

阅读时，使用映射的翻页键查看前后页；按“确认”打开阅读菜单，按“返回”关闭菜单或返回。

阅读菜单可提供章节、书签、查词、自动翻页、屏幕方向、跳转位置和截图等功能；具体以设备菜单为准。

首次打开 EPUB 可能需要生成分页缓存，之后再次打开通常更快。

4. 阅读设置

进入“设置 > 阅读 > 文字设置”，可调整字体、字号、行距、页边距和段落排版。屏幕方向、文字抗锯齿与图片显示等选项可在阅读或显示相关设置中查找。

更改字体、字号或排版后，图书可能需要重新分页。

5. 墨水屏刷新

翻页时短暂闪烁、反色或轻微残影通常是墨水屏的正常现象。

可在“设置 > 显示 > 刷新频率”调整完整刷新的间隔。如果残影明显，可按设备提供的操作执行手动全屏刷新。

6. 导入图书

SD 卡

关机后取出 SD 卡，用读卡器将图书复制到卡中，例如 /Books/ 文件夹。安全弹出 SD 卡并装回设备，然后从“书库”或“浏览文件”中打开图书。

Wi-Fi 传书

从主页进入“文件传输”，选择加入网络、创建热点或 Calibre 无线等可用方式。连接后，设备会显示二维码或 Web 地址；用手机或电脑浏览器打开地址，即可上传、下载或管理文件。

Web 文件服务没有登录认证，请仅在可信网络中使用。传输完成后退出“文件传输”。

7. 字体与词典

可从“设置 > 阅读 > 管理字体”安装字体。手动复制 .cpfont 字体时，请按照字体说明将字体家族文件夹放入 SD 卡的 /.fonts/ 或 /fonts/。

离线词典支持 StarDict 格式，可从“设置 > 阅读 > 管理词典”安装。

8. 休眠与电量

在“设置 > 系统 > 休眠时间”设置无操作后的自动休眠时间。

为了延长续航：

  • 传书完成后退出 Wi-Fi 传输。
  • 不需要时关闭设备具备的前光或蓝牙。
  • 选择适合自己的休眠时间。

9. 固件更新

只使用与设备型号匹配的 CrossMux 固件。可访问以下地址了解更新：

  • 官网：https://crossmux.com/
  • GitHub：https://github.com/0x1abin/crossmux
  • 版本发布：https://github.com/0x1abin/crossmux/releases

支持 OTA 的设备可进入“设置 > 系统 > 检查更新”。更新期间请勿断电、拔出 SD 卡或强制复位。

10. 常见问题

EPUB 打不开

1. 重启设备。

2. 删除这本书的缓存，然后重新打开。

3. 重新复制 EPUB 文件。

4. 用 Calibre 重新转换 EPUB。

5. 更新与设备匹配的 CrossMux 固件。

中文缺字

安装包含所需汉字的 .cpfont 字体，选用该字体后重新打开图书。

找不到 Wi-Fi 网络

确认网络使用 2.4 GHz Wi-Fi，并检查密码和信号强度。

设备无响应

如果设备有 Reset 键，可按下复位并重新开机；如果问题持续，请确认烧录的是对应型号的固件。

11. 注意事项

  • 不要弯折或重压电子墨水屏。
  • 定期备份 SD 卡中的重要图书和数据。
  • 不要随意删除 /.crosspoint/。
  • 不要刷入其他设备型号的固件。

更多信息：https://crossmux.com/
